## 🚀 How to Use

### For End Users
1. **Download:** `Renameify_v2.0.0.exe` from `dist/portable/`
2. **Extract** to any folder
3. **Run** the EXE
4. **Add API key** in Settings
5. **Select platform** (Plex/Jellyfin/Emby/Generic)
6. **Scan & Rename** your media

### For Developers
```bash
# Clone
git clone <your-repo-url>
cd renameify

# Install
pip install -r requirements.txt

# Run
python Renameify.py

# Test
python test_renameify.py

# Build
python build/build.py --portable
```

## 💡 What Was Fixed

### Before v2.0.0
```
❌ Batch of 25 files → Truncated JSON → Error
❌ Rate limit hit → Immediate failure (no retry)
❌ Web search error → Silent pass (no fallback)
❌ Model: gpt-4o-mini (weaker for identification)
❌ Batch size: 25 (too large for web search)
❌ Workers: 3 (too aggressive)
❌ Token calc: 512 + 150/file (not enough)
```

### After v2.0.0
```
✅ Batch of 48 files → Complete JSON → Success (32s)
✅ Rate limit hit → Exponential backoff (2s, 4s, 8s)
✅ Web search error → Fallback to chat completions
✅ Model: gpt-4o (better for identification)
✅ Batch size: 15 (safe for web search)
✅ Workers: 2 (rate-limit friendly)
✅ Token calc: 1024 + 200/file (generous buffer)
```
